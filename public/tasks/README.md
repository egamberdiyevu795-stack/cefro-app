# Task pictures

Pictures shown with speaking tasks (official Part 2 shows one beside the three questions). Every file here must be
original or freely licensed. Its source and licence are recorded twice: in the task's `picture` field
(`src/content/speaking/…`, stored in each task snapshot) and in the table below. A test checks the two agree.

The picture only sets the scene. The student answers the questions, not the picture. The evaluator is told what the
picture shows (the task's `alt` text) and that describing it answers no question.

## Adding a picture

1. Use an original drawing or a CC0 / freely licensed image. Never use a picture from an exam paper or a textbook.
2. Put it in this folder and set the task's `picture` (`src`, `alt`, `width`, `height`, `source`, `licence`,
   `licenceUrl`). Write `alt` as a plain description of what is in the picture: the evaluator reads it.
3. Add a row to the table above, and bump the task's `version`.
